Terminal de cobro para tu negocio

El cuaderno de ventas de tu negocio, ahora en dolares digitales

CLIQ es una app para cobrar en dolares digitales (USD₮) desde el mostrador de cualquier comercio — tienda, taller, puesto de feria o local de servicios. Cada venta queda anotada y firmada como un recibo que nadie puede alterar, y todo sigue funcionando aunque se corte internet.

Como empezar a usarlo

CLIQ corre como una app de linea de comandos en tu propio dispositivo — no hay servidor que levantar ni cuenta que crear. Necesitas tener instalado Node.js y pnpm.

git clone \
  https://github.com/Gabrululu/Cliq.git
cd cliq
pnpm add -g bare pear
pnpm install
bare index.js init
bare index.js help

Con eso ya tienes tu identidad de comercio creada y ves todos los comandos disponibles. Configurar la wallet para cobrar de verdad, crear facturas, verificar recibos y sincronizar entre dispositivos esta documentado paso a paso en el repositorio.
